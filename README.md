# API REST Express - Cine IPLACEX

API REST Express para administración de películas favoritas de empleados del IPLACEX.

## Descripción

Proyecto desarrollado en Node.js utilizando Express y MongoDB Atlas como base de datos. La API permite administrar información de películas y actores mediante operaciones REST.

## Tecnologías utilizadas

- Node.js
- Express
- MongoDB Atlas
- Docker
- Render

## Ejecución

Este proyecto está diseñado para ejecutarse solamente con Node.js.

Comando de ejecución:

npm install
node server.js

## Despliegue

La API se encuentra desplegada como Web Service en Render y conectada a una base de datos MongoDB Atlas.
